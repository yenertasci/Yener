# Tasarrufdevri 🚀

Bu proje, bireylerin bütçe yönetimi, tasarruf alışkanlıkları kazanması ve finansal farkındalığını artırması amacıyla geliştirilmektedir.

## Özellikler
* Kolay bütçe takibi
* Tasarruf hedefleri belirleme
* Günlük harcama analizleri
