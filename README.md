# Tasarruf Devri 🌿

Bu proje, içerikleri kod değiştirmeden kolayca yönetebilmek için özel bir yönetim paneli (`Panel.html`) ve Supabase veritabanı altyapısıyla hazırlanmıştır.

## 📁 Proje Dosyaları
- **Panel.html**: Yönetim arayüzü
- **Stylee.css**: Tasarım ve stil dosyası
- **script.js**: Veritabanı ve mantık işlemleri
- **index.html**: Ana web sitesi
